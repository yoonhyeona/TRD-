# 정담이 — 추억 사진 회상 활동 프로토타입

모바일 화면에 최적화한 정담이의 브라우저 실행형 데모입니다. 서버나 별도 API 키 없이 정적 파일만으로 실행할 수 있습니다.

## 실행하기

- `index.html`을 브라우저에서 열거나, 저장소를 GitHub Pages에 배포하면 됩니다.
- 로컬 개발 시에는 저장소 루트에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`으로 접속하세요.
- 폰트는 Google Fonts를 사용하며, 연결할 수 없는 환경에서는 시스템 글꼴을 사용합니다.

## 데모 흐름

1. **오늘의 활동 시작**을 누르고 예시 사진을 고르거나 JPEG/PNG/WebP 사진(최대 5MB)을 업로드합니다.
2. 이 브라우저에 대화 기록을 저장하는 데 동의한 뒤 활동을 시작합니다.
3. 세 번의 질문에 답하면 복약·컨디션 체크를 거쳐 요약과 활동 기록을 확인할 수 있습니다.
4. **활동 기록**에서 이전 세션을 확인하고, **설정과 동의**에서 동의를 철회하거나 기록을 삭제할 수 있습니다.

## 데이터·안전 안내

이 해커톤 프로토타입은 회원 인증, 서버 DB, Gemini API를 연결하지 않습니다. 대화와 요약은 예시 질문 및 로컬 템플릿으로 생성되며, 기록은 현재 브라우저의 `localStorage`에만 저장됩니다. 사용자가 업로드한 사진 원본은 `localStorage`에 저장하거나 서버로 전송하지 않고, 해당 페이지 세션의 미리보기에만 사용합니다. 브라우저 저장 공간을 지우면 데모 기록도 삭제됩니다. 공개 배포 전 실제 동의·인증·소유권 격리·비공개 사진 저장·삭제 작업을 구현하고 보안 검증해야 합니다.

정담이는 의료기기나 임상 진단 시스템이 아닙니다. 이 데모는 인지기능 또는 건강 상태를 판정하지 않습니다. 건강 관련 걱정은 보호자 또는 전문기관과 상의해 주세요.
